# microGPT-2

Учебная реализация архитектуры GPT-2 на PyTorch. Я собрал модель из основных частей трансформера и добавил простой цикл обучения предсказанию следующего токена. Цель проекта: разобраться, как данные проходят через модель и как обновляются её веса, а не получить качество большой языковой модели.

## Что реализовано

- токенные и позиционные эмбеддинги;
- причинное внимание: сначала расчёт одной головы и нескольких голов вручную, затем вариант на `scaled_dot_product_attention`;
- блок трансформера с нормализацией, остаточными связями и полносвязной сетью;
- выходной слой с общими весами с токенными эмбеддингами;
- подготовка батчей, обучение с AdamW, оценка ошибки на отложенном тексте, генерация и сохранение весов.

Модель создаётся со случайными весами. Готовая GPT-2 и предобученные веса не используются. PyTorch отвечает за тензорные операции и автоматическое дифференцирование, а `tiktoken` за токенизацию.
